# Mini-ERP-Sales-Invoicing-System

هذا المشروع هو نظام ERP بسيط لإدارة **العملاء، الفواتير، والأصناف**، يسمح بإدارة المبيعات والمخزون ومتابعة الفواتير بسهولة.

## الميزات الرئيسية

- **إدارة العملاء**  
  - إضافة، تعديل، وحذف العملاء.  
  - تخزين معلومات العميل الأساسية مثل الاسم، البريد الإلكتروني، ورقم الهاتف.  

- **إدارة الفواتير**  
  - إنشاء فواتير جديدة وإدارتها.  
  - دعم إضافة عدة أصناف لكل فاتورة مع الأسعار والكميات والخصومات.  
  - حساب الإجماليات: إجمالي المبيعات، الخصم، الصافي، وفرق القيمة.  
  - تعديل أو حذف أي سطر في الفاتورة قبل حفظها.  

- **إدارة الأصناف**  
  - إضافة وتعديل وحذف الأصناف.  
  - تحديد السعر الأصلي لكل صنف ومتابعة الكمية المتاحة.  
  - دعم الخصومات النسبية والمبلغية لكل صنف.  

- **تقارير وإحصائيات**  
  - لوحة تحكم (Dashboard) تعرض ملخص المبيعات والفواتير والأصناف.  
  - رسوم بيانية لتوضيح الأداء الشهري والفواتير حسب العميل أو الصنف.  

## التقنيات المستخدمة

- **Frontend**: Angular (Standalone Components + Reactive Forms)  
- **Backend**: أي خدمة API (يمكن الربط بـ Node.js/Express أو أي REST API)  
- **Charts**: Chart.js / Ng-ApexCharts (للعرض البياني في لوحة التحكم)  
- **Styling**: Bootstrap و Angular Material
